# Datasets

Dataset ZIPs are kept on the project SSD, not committed in full. The final five-class local training dataset directory is `datasets/5cat_prostheticobjects/` in the Windows workspace. See [source attribution](sources.md) and [preparation](preparation.md).

The Roboflow publishing workspace and dataset-version URLs document provenance but do not necessarily establish authorship of every underlying image. Verify applicable attribution/license terms before distributing images or derivatives.
