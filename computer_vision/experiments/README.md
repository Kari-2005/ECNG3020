# Computer Vision — Experiment Index

The ECNG3020 vision subsystem was developed through six iterative experiments. These are *development records*, not claims of finished physical prosthetic integration.

| No. | Experiment | Status |
|---|---|---|
| [01](01_initial_yolo/README.md) | Pretrained YOLO26n webcam baseline | Tested |
| [02](02_yolo_world/README.md) | YOLO-World open-vocabulary trials | Tested |
| [03](03_tennis_ball_apple/README.md) | Custom tennis-ball/apple detector | Trained and tested; metrics to archive |
| [04](04_14class_pilot/README.md) | Fourteen everyday-object classes | Trained; real-world limitations observed |
| [05](05_5class_model/README.md) | Focused five-object detector | Trained; initial webcam demonstration |
| [06](06_social_gestures/README.md) | MediaPipe social gestures | Three gestures demonstrated on webcam |

See [datasets](../datasets/README.md), [integration plan](../integration_plan.md) and existing [development logs](../docs/). Do not compare validation metrics from differently composed datasets as a controlled benchmark.
